# cs_hash_table
A basic hash table implementation in C for educational purposes

## What it does
This project implements a basic hash table in C, focusing on hashing, collision resolution, insertion, and deletion. It's designed to help students and educators understand the fundamental concepts of hash tables.

## Install
To use this project, clone the repository and compile the code:
```bash
git clone https://github.com/SamyAlderson/cs_hash_table.git
cd cs_hash_table
gcc -o hash_table hash_table.c
```
## Usage
To run the hash table, execute the compiled binary:
```bash
./hash_table
```
You can insert, delete, and display elements using the provided commands.

## Build from source
To build from source, run the following commands:
```bash
git clone https://github.com/SamyAlderson/cs_hash_table.git
cd cs_hash_table
gcc -o hash_table hash_table.c
```
## Project structure
The project consists of two main files:
- `hash_table.c`: The implementation of the hash table.
- `main.c`: A simple test driver for the hash table.
